## § 13. Increment A — Virlo throughput and fidelity (2026-08-11)

- **The fetch was unsorted, then all-time, now windowed (D46 W1).** `sources/virlo.py` asks for `order_by=created_at&sort=desc&limit=100`, pages `1..sources.fetch_pages`, videos only when `sources.include_videos`; a triple gate (stale / unenriched / used — FR-305/307) drops rows pre-rank and views-ranking applies among survivors; the wrapper's `get_top_videos`/`get_top_slideshows` gained `page`/`order_by`/`sort` with **local enum validation** (a client typo is an FR-119 error, never an opaque upstream 400). **`offset` is structurally unsendable** — `virlo_mcp/server._get` screens every query key against an allowlist at the single exit to Virlo, because Virlo answers `offset` with a hard HTTP 400.
