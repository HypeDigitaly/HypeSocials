## Defects found and fixed that the plan did not contain

1. **The Confirm gate would have lied on 4:5 images.** The tier is per PLATFORM but `render/profiles.py` clamps per RATIO, and `4:5` (Instagram images, FR-21) is a 1K-only ratio: a 2k config would be quoted $0.05 and rendered 1K. Closed by construction: `profiles.effective_image_tier(aspect_ratio, tier)` (public, one clamp table) is what `_image_price` prices, so a 4:5 image prices at `image.1k` while 1:1 / 9:16 / 16:9 price at `image.2k`. An unknown tier (`8k`) stays unpriced rather than being re-tiered (FR-282). No shipped config can hit the 4:5 case today (`run.formats.image` is 0 everywhere), but the invariant is what FR-342 promises. **`tests/test_budget.py`'s `entry()` helper defaults carousels to `4:5`** — real carousels are 1:1 (`plan.py:83`); tests that want the 2K price must pass `aspect_ratio="1:1"`.
2. **The plan's raw `" or "` scan would have flagged all 19 styles** ("no serif, script or display face" is a ban list, not a choice). The negation clause rule (spec'd by the conductor, implemented identically in the validator and the reference checker) keeps the scan deterministic and left 26 real choices to resolve, which the prose wave did.
3. **The plan's FR-347 had no notion of a ground line**, so a photographic wood table (`#B07C4A`, S 0.58) under a teal mug would have been a "two hue families" error — contradicting plan 4a rule 6. The validator is role-aware (background roles exempt) and gains rule 6 as its fourth finding (a saturated ground within 30° of the accent = no contrast), which is what forced the letterpress terracotta (13°) + vermilion (13°) pair into the open. The ≤ 1/8 bound is a validator finding, not only prose.
4. **`platform-showcase-card`'s empty kicker** was "else a teal rule or clear space" — resolved toward FR-340 (a zone with nothing quoted is LEFT OUT), not toward the rule. A small design change beyond "pick one value"; deliberate.
5. **PRD writer slips caught at review:** teal drift written as "30°/69°" (it is mean RGB drift, not hue degrees); "FR-341–355 reserved by D60" (D59 made the reservation); "14 carousel + 4 image styles" (all 19 are carousel-affine); "Next: FR-351+" (FR-356+); FR-342's sentence both refusing `2K` and asking for lower-casing (struck — case-sensitive like `reel_resolution`, test-pinned).
6. **K-SPEC's FR-348 example was wrong** ("grotesque + serif + mono in a zone → warn" is the tolerated mono carve-out). The test proves zone-named families count using `script` instead; the spec is scratch and dies with this session.
